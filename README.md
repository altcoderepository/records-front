- /app - инициальзация приложения, глобальные стили, роутинг и т д;
- /pages - Компоненты отдельных страниц, участвующих в маршрутизации;
- /widgets - Самодостаточные блоки интерфейса
- /features - Отдельные функциональные возможности (небольшие компоненты и много бизнес-логики)
- /entities - Доменные сущности приложения (модель данных и UI, контект, бизнес хуки)
- /shared - слой для переиспользвуемых сущностей (UI компоненты без доменной логики, API, хелперы)
